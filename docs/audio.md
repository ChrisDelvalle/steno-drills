# Self-paced audio

Audio adds a presentation and speech layer to existing word practice. It does not change target selection, exact spelling, grouping, correction rules, or the WPM formula. Transcripts and continuous dictation are outside this release.

`WordPracticeProjection.prompt` identifies a group/pass and its native source boundary. Its ID advances after an exact final tail, before that tail receives a separator. Committing the separator keeps the same ID; editing the tail restores the previous one. Midgroup mistakes keep the same prompt. Speech consumes this logical projection rather than caret movement, so arrow keys, hint toggles, replay, and focus changes cannot create attempts or errors.

`SpeechAdapter` isolates browser voice discovery, playback, cancellation, and callbacks. The browser adapter filters on `localService` and English language tags, then selects the saved available voice, local English default, or first local English voice. It subscribes to `voiceschanged` for delayed discovery. The API and local/remote distinction are documented by [MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis) and [localService](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService).

`PromptSpeaker` requires initial activation, cancels superseded utterances, and ignores stale callbacks using a generation counter. Missing voices, denied playback, thrown errors, and an eight-second start timeout report a concise failure. The session clock begins on the first valid start callback. Cancellation never pauses an already-started clock. Restart retains activation but resets the clock until the new utterance starts. Page/window focus loss cancels speech without automatically replaying on return.

Full keeps the measured passage. Current measures only the prompt's group and renders complete rows. Hidden renders entered text only, wrapping it into explicit rows using the fixed typography; no expected-word elements, measurement ruler, titles, chord answers, or accessibility descriptions are mounted before reveal. Its empty geometry is independent of expected word lengths. Raw pending input has a neutral annotation. Reveal uses prompt-local state and clears on progress; it does not write the hint preference. Hidden answers stay concealed when speech is unavailable.

Listening preferences live in the session profile and backups. The preferred voice URI is a separate personal field. Old profiles migrate to audio off, Full, 1× and Automatic voice. Audio-off sessions always show Full while retaining the inactive display and rate. Shared v5 links carry only audio, display, rate, and existing test constraints; v1–v4 are unchanged and explicitly disable audio.

Automated tests cover prompt/tail sequencing, group retries and recovery, strict corrections, raw outlines, exact homophones, native buffer edits, playback timing, restart, deadlines, cancellation, stale callbacks, local-only discovery, missing/blocked/failed playback, hidden-answer exposure, profile/backups, wire fixtures, and shared-state editing/save/exit. Release QA also checks desktop/320px/393px layouts, themes, ten dots, long input, focus recovery, and native local-voice playback through the production build.
