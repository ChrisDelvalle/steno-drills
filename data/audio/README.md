No personal recording or Plover configuration is accessed.

`catalog.json` is generated from the bundled dictionary and classifier with every concept enabled and no personal corrections or exclusions. It partitions common vocabulary and records the qualifying outline/pronunciation relationships. `overrides.json` provides explicit synthesis spellings and unresolved variants. Alternative American pronunciations can include vowel mergers; phoneme-recognition output is only a review aid.

`published.json` points to the content-hashed public manifest. `provenance.json` records the generation recipe, model revision, coverage, fallback cases, codec settings, measured inference time, and production size. Lossless word masters and intermediate reviews stay under ignored `.audio-audition/production`, preserving prior masters when an input changes. Normal builds use only the committed public assets and require no model or Python environment.

Generation uses English, a terminal period, temperatures 0.5/0.3/0.1/0 on deterministic retries, top-p 0.8, top-k 20, and a 64-token limit. The requested repetition penalty is 1.05; the pinned Base model's ICL path enforces a minimum of 1.5. The seed starts at 1729 with deterministic word/voice offsets. Processing retains 80 ms guards, targets −22 dB RMS, and limits peaks to −1 dB. These values are pinned in the generation code/config and retained with each accepted master's checksum and attempts.
